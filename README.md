# 鍵盤大逃亡 · KEYBOARD ESCAPE

一個 Roblox **obby** 風格嘅網頁逃脫遊戲 —— 純鍵盤操作、單一 HTML 檔案、零依賴、雙擊即玩。

用 canvas 2D 做偽 3D 透視渲染，跑四關障礙賽：跳平台、避熔岩、閃旋風刀、踩移動浮台，衝去金色逃脫門。

**▶︎ 即刻玩**：<https://sorosyeung-netizen.github.io/keyboard-escape/>

---

## 玩法

| 按鍵 | 用途 |
| --- | --- |
| `W` `A` `S` `D` / 方向鍵 | 前後左右移動 |
| `空格` | 跳躍（可以跳過旋風刀） |
| `P` | 暫停 / 繼續 |
| `R` | 重玩本關 |
| `Enter` | 開始遊戲 / 前往下一關 |

## 四關

| 關 | 名稱 | 考驗 |
| --- | --- | --- |
| 1 | 熱身跳台 | 基礎跳躍、平台間距判斷 |
| 2 | 熔岩渡橋 | 熔岩、x 軸移動浮台、碎裂平台 |
| 3 | 旋風刀陣 | 六把旋轉刀的起跳時機 |
| 4 | 終極大逃亡 | y 軸升降台、闊台旋風刀、長距離衝刺 |

## 機關

- **熔岩** — 觸到即死，重生於最近檢查點
- **旋風刀** — 繞垂直軸旋轉嘅殺傷棍，靠 y 軸高度重疊判定；跳起可以避開
- **移動浮台** — 沿 x 或 y 軸正弦振盪，要預判相位先跳得中
- **碎裂平台** — 站上去 0.5 秒後消失，4.6 秒後復原
- **檢查點** — 藍色光柱，經過即記錄重生點
- **逃脫門** — 金色傳送門，碰到即通關

## 技術細節

單檔 `index.html`，無任何外部依賴（無 CDN、無 npm、無第三方庫）。

**渲染**：canvas 2D ＋ 透視投影，按深度排序畫 box，玩家用 billboard ＋ 影子橢圓。

**物理**：AABB 逐軸碰撞解析（`moveAxis`），每步 ≤ 0.32 單位、最多 8 步子步進防高速穿隧；含土狼時間（0.12s）與滯空控制力（0.55）。

| 常數 | 值 |
| --- | --- |
| 重力 | 26 |
| 跳躍初速 | 9.6 |
| 跑速上限 | 7.2 |
| 加速度 | 62 |
| 跳高 / 滯空 | 1.77 單位 / 0.738 秒 |
| 最大跳距 | ≈ 5.3 單位 |

**零未來函數**：遊戲本身嘅障礙判定只依賴當前狀態，唔會偷睇未來。

## 驗證

遊戲附帶一套機械驗證腳本（無頭 ＋ 真瀏覽器），確保「真係玩得到、真係通得到關」：

- **無頭樁台**：62 項斷言全 PASS，每關再跑 4 個相位偏移 = 16/16 通關（避免撞彩數）
- **真 Chromium**：四關連續通關到 ALL CLEAR，零執行期錯誤，真按鍵輸入有效
- **可達性窮舉**：暴力搜索確認各關旋風刀區存在大量可行路線
